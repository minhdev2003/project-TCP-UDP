# project-TCP-UDP

A Python project for experimenting with TCP and UDP networking concepts, socket communication, and client/server interactions.

## Overview

This repository is intended to explore and demonstrate:

- TCP client/server communication
- UDP datagram communication
- Socket programming basics in Python
- Simple network application patterns

## Project Goals

- Learn how TCP and UDP sockets behave differently
- Build small, educational network examples
- Provide a clean starting point for socket-based projects

## Requirements

- Python 3.x
- Standard library modules such as `socket`, `threading`, and `time`

## Example Usage

Run a TCP or UDP server/client sample using Python:

```bash
python server.py
python client.py
```

Or for UDP:

```bash
python udp_server.py
python udp_client.py
```
